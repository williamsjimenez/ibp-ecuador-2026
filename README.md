# Atlas territorial del Índice de Bienestar Policial 1.0

Mapa interactivo de las 26 subzonas policiales del Ecuador, con índice global y cinco dimensiones. Prototipo científico de discusión y validación, no clasificación institucional definitiva.

Los datos geográficos y las puntuaciones se incluyen en `datos/`; el mapa usa Leaflet sobre fondo blanco. Los valores proceden del informe estadístico descriptivo de noviembre de 2026 y contienen proxies territoriales, por lo que no deben tratarse como medidas individuales representativas.

**Publicación:** `https://williamsjimenez.github.io/ibp-ecuador-2026/`. Para habilitar Pages: Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
